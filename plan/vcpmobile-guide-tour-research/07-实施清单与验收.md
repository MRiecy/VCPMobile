## 阶段 2：GuideOverlay 与动画原语

- `components/GuideOverlay.vue`：全屏黑纱（rgba 55%，无 backdrop-filter）+ 目标聚光（box-shadow 挖洞 + 2px 描边）+ 卡片（[n/m] 等宽计数、标题、正文、下一步/我知道了 两枚按钮）+ 方位四向自动翻转（约束在 `--vcp-safe-*` 内）。
- 动画原语：`press-hold`（ghost 手指 + 600ms 进度环）、`swipe-right`（手指右滑 80px + 行示意位移回弹）、`drag-vertical`（按住 + 行上浮 + 上下轨迹示意，不回写真实顺序）。纯 CSS keyframes + SVG，无新依赖，循环 1–2 次定格。
- 几何：每步 scrollIntoView 居中；ResizeObserver + window resize + `vcp-keyboard-inset` + `vcp-lifecycle-changed` 重算；waitFor 轮询 100ms/3s 超时静默越过该步；**rect 稳定判定（连续两次采样一致且位于视口内）后才测量聚光**；整场不可解析 → finish 防死循环。
- 挂载：`src/App.vue` READY 后 `<GuideOverlay />`（z-guide，紧随 GlobalOverlayManager）。

## 实现约束（Magi 审查，见 05 文档）

1. **predicates 纯函数化**：只读响应式状态；断点用响应式封装（VueUse useMediaQuery），禁止裸 `window.matchMedia`。
2. **防重评估风暴**：评估只做纯读比较；`start()` 前经 settleMs（默认 600ms）稳定期；同一时刻至多启动一场（其余入 pendingQueue）。
3. **异常退出保障**：卡片「下一步/我知道了」始终可点、末步始终可达（步骤 ≤2 + 目标失败自动越过该步）；卡片层 pointer-events-auto 独立于目标解析状态。
