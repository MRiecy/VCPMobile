# 01 — 演示流程详解：以「长按亮暗模式按钮」为例

> 目的：回答「演示完整流程细节和具体会发生什么」，用一场 2 步的迷你指引逐步还原用户在屏幕上的所见所闻。
> 状态：✅ 最终稿（Q3 纯动画演示+按钮推进、Q5 禁止返回键、Q4 前置条件模型；第 6 轮按钮模型简化为两枚）。

## 0. 前提事实（代码证据）

- 按钮位于聊天页头部右侧（`src/features/chat/ChatView.vue:301`）。
- 单击 = 切换深/浅主题（`themeStore.toggleTheme()`）。
- 长按 600ms = 打开「消息呈现模式」菜单（`v-longpress.suppress-click` → `openPresentationMenu`，气泡/面板/杂志三选一）。
- `suppress-click` 保证长按成功后不会顺带触发单击切换主题。
- 该按钮**只在有消息的话题里教学才有意义**（用户第 2 轮指正）：排版切换的效果需要 ≥4 条消息才可见。触发前置条件见 §1。

## 1. 触发：这场指引何时出现（前置条件模型，Q4）

全部满足才自动播放（一次性）：

1. 依赖：`sidebar-gestures`（左边栏拖拽+右滑）教学**已完成**——用户必须先学会 agent 相关手势；
2. 当前话题已加载，且**非 system 消息数 ≥4**（识别标准同自动话题总结，`chatHistoryStore.ts:138-142`）；
3. 话题标题**不再是默认格式**（不匹配 `/^(新话题|新会话) \d{2}:\d{2}:\d{2}$/`，同自动总结标准 `chatHistoryStore.ts:137`）；
4. 左边栏、右边栏均未打开——处在干净的聊天主界面。

条件齐备并稳定 0.6 秒后，自动进入演示。

## 2. 第 1 步：动画演示（屏幕上逐步发生的事）

**① 黑纱落下（约 150ms 淡入）**
- 整个界面覆盖一层约 55% 透明度的黑色遮罩，画面变暗，所有内容「沉」下去。
- 此刻起整个界面进入**演示模式**：滑动、点击、返回手势全部被教学层接管，真实业务不会响应（不会误切主题、不会误发消息）。

**② 聚光灯亮起**
- 唯一例外是「亮暗模式」按钮：它没有被黑纱盖住，保持原样清晰可见，周围多了一圈 2px 高亮描边（Accent Bar 风格，符合美学宪法）。

**③ 指引卡片浮出（约 200ms 微位移动画，无弹跳）**

```text
┌───────────────────────────────┐
│ [1/2]  亮暗模式        MONO   │  ← 步骤计数用等宽字体
│ 单击：切换深色/浅色主题       │
│ 长按 0.6 秒：切换消息呈现样式  │
│ ───────────────────────────── │
│                     [下一步 →] │
└───────────────────────────────┘
```

- 「下一步」= 看完动画后手动推进（Q3 裁决：只靠按钮推进，不检测手势）；本指引仅 2 步，末步「我知道了」即退出并记录完成态。

**④ 演示动画自动播放（Q3 核心设计，用户全程只需看）**
- 一个 ghost 手指图标（半透明手形）从卡片一侧移入，停在按钮正上方。
- 手指按下：按钮高亮描边开始出现**缓慢收拢的进度环**，0.6 秒走满——把长按的「门槛感」可视化（用户此前可能按 0.3 秒就松手、误以为没效果）。
- 进度走满瞬间，按钮旁弹出一个**示意小卡**：气泡 / 面板 / 杂志 三个选项的迷你示意（纯视觉插图，真实菜单并未弹出）。
- 动画循环播放 1–2 次后定格，等待用户操作。

**⑤ 关键：演示归演示、真实归真实**
- 全过程不检测用户手势、不触发真实业务：真实 `v-longpress` 不会执行，`openPresentationMenu` 不会弹出，主题不会被切换。
- 教学结束后，用户用自己的手指去真实操作。

## 3. 第 2 步：效果说明 + 收尾

- 用户点「下一步」后，卡片推进到第 2 步：

```text
┌───────────────────────────────┐
│ [2/2]  刚刚演示了一次长按      │
│ 真实效果：弹出「消息呈现」菜单，│
│ 可在 气泡 / 面板 / 杂志 间切换。│
│ 现在去按住按钮 0.6 秒试试吧！  │
│ ───────────────────────────── │
│               [我知道了]      │
└───────────────────────────────┘
```

- 「我知道了」：黑纱淡出（约 200ms），界面恢复可操作，完成态写入本地存储，此后永不再自动弹出（可从设置 → 帮助与指引回放）。
- **返回键全程无效**（Q5 裁决）：防止误触返回后没看清；唯一退出出口是末步「我知道了」。
- 示意卡为流程示例；最终卡片文案以 `06-教学文案占位稿.md` 为准。

## 4. 时间轴总览

```text
t=0s    触发：黑纱淡入，聚光锁定亮暗按钮
t=0.2s  卡片浮出（步骤 1/2，单击/长按说明 + 下一步）
t=0.3s  演示动画：ghost 手指按下 → 0.6s 进度环 → 三选项示意卡
t=?     用户点「下一步」→ 卡片推进到步骤 2/2（效果说明 + 我知道了）
t+?     用户点「我知道了」→ 黑纱淡出 → 完成态持久化
```

全程用户只需：看动画 → 点「下一步」→ 点「我知道了」。总耗时约 15–20 秒，无需任何手势练习。

## 5. 为什么这样设计（要点复述）

1. **动画演示替代手势练习**（Q3）：操作都很简单，用户不需要被逼着做手势；看一遍动画 + 点按钮即可，教学更轻。
2. **零副作用**：演示期间真实业务被拦截，不会误切主题/误弹菜单。
3. **阈值可视化**：0.6 秒进度环把长按门槛外化。
4. **环境前置**（Q4）：只在「≥4 条消息 + 非默认标题 + 干净主界面 + 已学会左边栏手势」时才教，保证教学结束后用户真实尝试时效果立即可见。
5. **返回键禁止**（Q5）：教学信息密度低、步数少，宁可封死返回也不让用户误触丢失上下文。
