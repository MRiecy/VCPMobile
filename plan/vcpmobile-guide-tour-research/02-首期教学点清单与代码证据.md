## 「识别标准同自动话题总结」的精确定义

来源：`src/core/stores/chatHistoryStore.ts:127-142`（`summarizeTopic` 触发条件）：

- 默认标题正则：`/^(新话题|新会话) \d{2}:\d{2}:\d{2}$/`（即「新话题 HH:MM:SS」或「新会话 HH:MM:SS」）；
- 消息计数：`currentChatHistory` 中 `role !== "system"` 的消息数 ≥4；
- 因此用户要求的「标题不以新话题…开头」在引擎中实现为：**标题不匹配上述默认正则**（即话题已被 AI 总结重命名，是「成熟」话题）。

## 差异修正（重要）

### 修正 A：拖拽排序 = 按住整行约 0.2 秒后上下拖动

- 事实：Sortable 的 `handle` 指向**整行容器**（`AgentList.vue:315-321` 中行 wrapper 自身就是 drag-handle），按在行内任何位置都算按住把手；`delay: 200`（仅触屏）+ `touchStartThreshold: 3` 表示**按住约 0.2 秒、移动超过 3px** 后才进入拖拽。
- 演示动画（Q3）需表达：按住 → 行半透明上浮 → 上下移动 → 松手落位。

### 修正 B：右滑与拖拽是同一手势家族的两个分支

- 事实：行内手势由 `onTouchStart/Move/End` 判定方向（`AgentList.vue:142-150`，SWIPE_THRESHOLD 50 / MAX_SWIPE 80）：**横向滑动 = 右滑露出设置按钮；按住不动再上下拖 = 排序**。
- 教学顺序建议：先教右滑（更简单、单个手势），再教拖拽排序（按压 + 移动两步）。

### 教学点 1：长按「亮暗模式」按钮

- 代码：`ChatView.vue:301-305`，600ms 阈值（`core/directives/longpress.ts:11`）。
- 前置条件（Q4，用户定义）：①已完成 `sidebar-gestures`；②非 system 消息 ≥4（排版切换效果可见）；③标题非默认格式；④左右栏未遮挡。
- 演示动画：`press-hold`（ghost 手指 + 0.6s 进度环）+ 三选项示意卡。详见 01 文档。

### 教学点 2：长按聊天框「+」按钮

- 代码：`InputEnhancer.vue:548-558`，`v-longpress` → `openTarvenSelector` + 单击 → 附件菜单。
- 单击 = 附件菜单（相机/相册/文件，+ 图标旋转 45°）；长按 = Tarven 规则选择器（对外文案：上下文注入管理器 / 上下文注入规则）；绿色小点 = 有启用中的规则。
- **前置条件硬性存在**：无话题时整个输入区 `opacity-70 pointer-events-none`，placeholder 为「请先选择话题以开启对话」（`InputEnhancer.vue:427, 503-504`）。
- 演示动画：`press-hold` + Tarven 选择器示意卡。

### 教学点 3+4：左边栏拖拽排序与右滑

- 代码：Sortable 见 `AgentList.vue:70-136`；右滑露出按钮见 `AgentList.vue:142-150`（group 紫 `323-339` / agent 蓝 `380-396`）。
- 前置条件：左边栏可见（手机为 drawer 打开；平板 ≥1024px 常驻栏不算遮挡）+ 同类型 ≥2 项（排序才有意义；右滑 ≥1 项即可）。
- 演示动画：第 1 步 `swipe-right`（手指右滑轨迹 + 行位移 80px 露出设置按钮的纯视觉示意，真实行不动）；第 2 步 `drag-vertical`（手指按住 + 行上浮 + 上下移动轨迹示意，不回写真实顺序）。
- **教学目标（第 6 轮确定）：高亮对象锁定「排位第一个 Agent」，不选 group**（group 非人人都有）。
- **定位机制（100% 可达的前提与兜底）**：
  1. 锚点按 id 动态注册：`AgentList.vue:378` 行 wrapper 加 `v-guide="agent-row-<id>"`；列表为平铺 v-for（未虚拟化），`key = agent.id`，元素可被唯一寻址。
  2. 「第一位」判定与渲染同源：抽取 `AgentList.vue:46-60` 的排序逻辑为共享函数（agentOrder 优先、未知 id 置后），guide 定义用同一函数算出第一位 id 再查注册表，L4 契约测试防分歧。
  3. 目标行可能不在 DOM 的两种情况：搜索过滤（`AgentList.vue:372-377` 按 searchQuery 过滤）或左边栏切到 topics 页签（`AgentSidebar.vue:76` v-if）。→ 把「目标行已挂载」做成响应式触发谓词（目标注册表用 reactive Map），行不在 DOM 时不触发指引，行出现后自动触发。
  4. 位置获取：AgentSidebar 常驻挂载（`App.vue:520` 无 v-if），手机端抽屉关闭时行在屏外——谓词含「左边栏可见」；抽屉滑入动画期间 rect 未稳定——步骤 waitFor 要求连续两次采样 rect 一致且位于视口内再测量；列表滚动偏移——scrollIntoView 居中。
  5. 兜底：任一条件不满足 → 不触发或该步静默越过，永不卡死、永不错位。
