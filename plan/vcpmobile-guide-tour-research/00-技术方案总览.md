> 状态：✅ 最终稿。第 1 轮方案评审定稿（用户确认）；第 2 轮修订 Q3 纯动画演示+按钮推进、Q5 禁止返回键、Q4 前置条件模型；第 5 轮 D1/D2 用户确认；第 6 轮 sidebar 高亮目标锁定第一个 Agent、按钮模型简化为两枚。决策日志见 04。

## 1. 目标与成功标准

- **目标**：为现有「点击/长按」等隐蔽交互提供零空间成本的可视化发现机制，并支持未来新功能上线时的版本化指引。
- **成功标准**：
  1. **零新增依赖、零新增常驻 UI**：不加任何按钮/入口占位，仅靠锚点属性 + 全局覆盖层。
  2. 指引覆盖层高于一切业务 UI（新语义层 `guide = 95`，位于 toast 90 与 boot 100 之间），低于 BootScreen/PermissionGate。
  3. 完成态持久化（重启后不重复骚扰）、可从设置页回放、应用升级后自动挂起「新功能指引」。
  4. 长按类交互获得可视化演示且演示过程不误触真实业务。
  5. `pnpm check` 与 `pnpm test:run` 全绿，治理测试（禁 backdrop-filter、禁裸 env(safe-area-inset)）通过；真机三宽度验收。

## 2. 技术选型：自研轻量 Coachmark 引擎（约 400–500 行）

**不引入第三方库**（driver.js / intro.js / shepherd.js / vue-tour）：

- **维护风险**：driver.js 原仓库已归档，社区版分裂；vue-tour 长期停更。
- **许可风险**：intro.js 商用需付费授权（本项目为商业化产品）。
- **体积与依赖**：shepherd.js 依赖 popper 全家桶，与「APK 体积敏感」方针冲突。
- **样式成本反而更高**：美学宪法（禁大面积圆角、禁毛玻璃、2px Accent Bar、灰度优先、内敛动画）与治理测试（`MobileUiCompatibility.test.ts` 自动扫描全部生产源码禁止 `backdrop-filter`、禁止裸 `env(safe-area-inset)`）意味着任何第三方库都必须深度重写样式。
- **集成成本**：Android 返回键由自研 `useModalHistory` 状态机统一管控，第三方库不感知，需额外适配层。

**自研成本低的依据**（全部基础设施已存在）：语义化层级三件套（`layers.ts`/`uno.config.ts`/`themes.css`）、`useModalHistory` 返回键栈、`pinia-plugin-persistedstate`（`persist.pick` 模式见 `chatSessionStore.ts:249`）、`v-longpress` 指令先例（600ms、suppress-click，`core/directives/longpress.ts`）、Teleport 覆盖层模式（`GlobalOverlayManager`）、静态指引先例（`BatteryOptimizationGuide.vue`）。

## 3. 架构要点

### 3.1 视觉与交互模型

- **聚光高亮**：目标矩形上覆盖绝对定位 div，`box-shadow: 0 0 0 9999px rgba(0,0,0,0.55)` 打出暗化遮罩 + 2px 高亮描边。不使用 SVG mask、不使用 backdrop-filter（chrome87 兼容、单 Composite Layer、治理测试零风险）。
- **演示模式（第 2 轮修订，Q3/Q5）**：指引激活期间覆盖层全屏拦截指针事件（touch-action 锁定，背景不可滚动、不可交互）。**不做手势检测、不触发真实业务**——操作过程由 GuideOverlay 内建演示动画展示（`press-hold` ghost 手指按压 + 600ms 进度环 / `swipe-right` 右滑轨迹 / `drag-vertical` 拖拽轨迹），步骤推进全靠卡片按钮（**下一步** / **我知道了**，共两枚；指引仅 1–2 步）。返回键在指引激活期间**被完全禁止**（注册 modal history 且 close 返回 false，复用 syncSession 的 canDismiss 模式），唯一退出出口是末步的「我知道了」按钮。
- **指引卡片**：复用现有 token（`--secondary-bg`/`--vcp-panel-bg-97`/`--border-color`/`--primary-text`），圆角 ≤12px，步骤计数 Monospace，微淡入位移动画（无缩放弹跳）。
- **卡片方位**：上/下/左/右四向自动选择 + 视口翻转，坐标约束在 `--vcp-safe-*` insets 内。

### 3.5 触发策略

1. **前置条件触发 + 自动播放**（第 2 轮裁决 Q1=自动播放、Q4=前置条件模型）：每场指引声明 `trigger`（依赖的已完成指引 + 状态谓词），全部满足且未完成过 → 自动进入演示（一次性）。详见 §3.6。
2. 版本升级：`getVersion()` 对比持久化 `lastSeenAppVersion`，`introducedIn > lastSeenVersion` 的指引入队，Toast 提示（不强制打断），随后更新版本。
3. 手动回放：设置 → 帮助与指引。

### 3.6 前置条件模型（第 2 轮裁决 Q4）

```ts
interface GuideTrigger {
  requires?: string[];                       // 依赖的已完成指引 id（如 theme-longpress 依赖 sidebar-gestures）
  predicates?: { name: string; check: () => boolean }[];  // 状态条件，全部满足才可触发
  settleMs?: number;                         // 条件齐备后的稳定期（默认 600ms，防抖动）
}
```

- 评估机制：guideStore 用 Vue 响应式收集 predicates 依赖，任何相关 store / 路由 / 页面栈变化后重评估所有未完成指引；全部谓词 + 依赖完成 → 自动 start。目标元素注册表亦为响应式（reactive Map），支持「目标行已挂载」类谓词（见 02 定位机制）。
- 首期四场指引的触发规格见 `03-触发策略与边界分析.md`。

## 4. 边界与失败模式

- 目标未渲染：waitFor 超时**静默越过该步**；全部步骤不可解析 → finish 并记录完成态（防死循环）。
- 滚动容器：scrollIntoView 居中；激活期间锁定背景滚动；连续两次采样 rect 一致且位于视口内才测量聚光。
- 折叠/旋转：ResizeObserver + resize 重算。软键盘：`vcp-keyboard-inset` 重算。前后台：resume 重算，不终止。
- 返回键：指引激活期间**完全禁止**（Q5 裁决），唯一退出出口是末步「我知道了」（指引仅 1–2 步，出口一步可达）。
- 重复 start：pendingQueue 排队串行播放。
- PermissionGate(110)/BootScreen(100) 高于 guide(95)，属预期；v1 指引避开权限步骤。
