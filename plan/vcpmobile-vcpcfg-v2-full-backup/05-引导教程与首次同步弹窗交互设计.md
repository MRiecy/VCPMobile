# 05 - 引导教程与首次同步弹窗交互设计

## 1. 交互目标与心智模型

用户在多设备迁移或重装场景下的心理诉求是：**最少的手动输入、清晰的进度可知感、无遗漏的数据还原**。

为了达成用户所提设想：“新增一个引导教程教导用户怎样操作，首次同步后也可以弹窗提示导入配置等”，系统设计构建两条相互呼应的交互链路：
1. **冷启导流链路（Onboarding Wizard）**：空机初次启动时，主动引导用户优先导入 `.vcpcfg.json`，完成网络参数秒级回填；
2. **同步收尾闭环链路（Post-Sync Smart Prompt）**：首次数据同步完成后，系统主动感知并弹出友好提示，一键补全此前跳过的智能体与群组本地偏好。

## 2. 首屏配置引导向导（Empty-State Onboarding Wizard）

### 2.1 触发门限判定
在 `App.vue` 挂载或 `appLifecycle` 初始化时求值纯函数断言：
```typescript
const isFreshInstall = computed(() => {
  const settings = useSettingsStore().settings;
  const assistantStore = useAssistantStore();
  // 未配置服务器且本地无助手或群聊数据
  return !settings?.server?.url && assistantStore.agents.length === 0 && assistantStore.groups.length === 0;
});
```

## 4. 首次数据同步完成智能弹窗（Post-Sync Re-import Prompt）

### 4.1 挂载位置与时序捕获
物理入口位于 `src/core/stores/syncSession.ts` 的 `stopAndReload()` 闭环内：

```typescript
// 物理调用链: syncSessionStore.stopAndReload() -> performFullReload() 完成后

if (needsReload.value) {
  try {
    await useDataReload().performFullReload();
    needsReload.value = false;
    
    // 【新增点】：检查是否存在未完成的本地配置补全需求
    void checkAndPromptPendingConfigRestore();
  } catch (error) { ... }
}
```

### 4.2 智能恢复判定逻辑 (`checkAndPromptPendingConfigRestore`)
```typescript
export async function checkAndPromptPendingConfigRestore(): Promise<void> {
  const overlay = useOverlayStore();
  const assistantStore = useAssistantStore();
  const pendingConfig = getPendingConfigState(); // 读取 localStorage 暂存标记与载荷

  // 判定条件：
  // 1. 本机刚同步回了助手或群聊（数量 > 0）；
  // 2. 之前导入时记录了缺失实体（hasPendingEntities === true）；
  const totalEntities = assistantStore.agents.length + assistantStore.groups.length;
  if (!pendingConfig.hasPendingEntities || totalEntities === 0) {
    return;
  }

  // 唤起二次恢复模态弹窗 (使用全局覆盖层的 showConfirm API)
  const confirmed = await overlay.showConfirm({
    title: '同步已完成 · 恢复助手专属配置',
    message: `已成功同步 ${assistantStore.agents.length} 个智能体与 ${assistantStore.groups.length} 个群聊数据。检测到您此前的备份中包含专属移动端提示词、独立音色与群聊模式，是否现在补全？`,
  });

  if (confirmed) {
    if (pendingConfig.stagedPayload) {
      // 极速直接应用已暂存的 agentPreferences & groupPreferences
      await applyStagedEntityPreferences(pendingConfig.stagedPayload);
    } else {
      // 降级：唤起原生文件选择器让用户再次确认文件
      await pickAndApplyConfigBackup();
    }
    clearPendingConfigState();
  }
}
```

弹窗采用内敛的反馈样式，使用 2px Accent Bar 高亮侧边条，Monospace 显示待补齐条目计数，给予用户严谨的技术掌控感：

├────────────────────────────────────────────────────────┤

│  • [Agent] 移动端精简提示词与独立发音 (12 项)          │
