# 01 - 数据全景审计与非同步配置清单

## 1. 审计方法与边界准则

依据项目根目录 `AGENTS.md` 铁律，生产代码是实现事实的唯一来源。本审计基于物理代码库：
- Rust 同步 DTO：`src-tauri/src/vcp_modules/sync/sync_dto.rs`
- 智能体类型与仓储：`src-tauri/src/vcp_modules/agent/agent_types.rs`、`src-tauri/src/vcp_modules/persistence/agent_repository.rs`
- 群组类型与服务：`src-tauri/src/vcp_modules/group/group_types.rs`、`src-tauri/src/vcp_modules/group/group_service.rs`
- 数据库基线迁移：`src-tauri/migrations/0100_baseline_v2.sql`、`0104_group_local_settings.sql`、`0105_agent_voice_config.sql`
- 模型管理与 Tarven 引擎：`src-tauri/src/vcp_modules/infra/model_manager.rs`、`src-tauri/src/vcp_modules/chat/tarven_engine.rs`

## 2. 智能体 (Agent) 字段全景对比矩阵

| 字段名 (驼峰 / 下划线) | 字段类型 | 存储位置 | 是否进入 Sync DTO | 是否计入 config_hash | 语义与所属所有者 | 是否纳入 .vcpcfg 备份 |
|---|---|---|:---:|:---:|---|:---:|

| `name` | `String` | `agents.name` | **是** | **是** | 智能体名称（双端同步） | 否 (归同步) |
| `systemPrompt` / `system_prompt` | `String` | `agents.system_prompt` | **是** | **是** | 角色通用提示词（双端同步） | 否 (归同步) |
| `mobileSystemPrompt` / `mobile_system_prompt` | `String` | `agents.mobile_system_prompt` | ❌ **不同步** | ❌ **不计入** | **移动端专用系统提示词**。对话组装时优先级：`mobile_system_prompt > system_prompt`。允许手机端拥有更精简、触控格式友好的独立人设 | ✅ **必须备份** |
| `model` | `String` | `agents.model` | **是** | **是** | 绑定的基础大模型名称 | 否 (归同步) |

| `contextTokenLimit` / `context_token_limit` | `i32` | `agents.context_token_limit` | **是** | **是** | 上下文 Token 限制 (默认 1,000,000) | 否 (归同步) |
| `maxOutputTokens` / `max_output_tokens` | `i32` | `agents.max_output_tokens` | **是** | **是** | 单次最大输出 Token (默认 64,000) | 否 (归同步) |
| `streamOutput` / `stream_output` | `bool` | `agents.stream_output` | **是** | **是** | 是否启用流式输出 | 否 (归同步) |

| `voice` / `voice_config` | `AgentVoiceConfig` | `agents.voice_config` (JSON) | ❌ **不同步** | ❌ **不计入** | **移动端独立发音音色**。关闭时继承全局语音设置；开启时指定本助手独立音色与参数 | ✅ **必须备份** |
| `avatarCalculatedColor` | `Option<String>` | `avatars.dominant_color` | 否 | 否 | 头像图片提取的主色调，派生展示字段 | 否 |
| `topics` | `Vec<Topic>` | `topics` 物理表 | 否 (独立同步) | 否 | 话题列表实体 | 否 (归同步) |

### 智能体独立音色结构 (`AgentVoiceConfig`) 拆解
```rust
pub struct AgentVoiceConfig {
    pub enabled: bool,          // 是否启用助手独立音色 (false 时继承全局默认)
    pub mode: VoiceTtsMode,     // 发音模式: "builtin" (预置) 或 "clone" (声音复刻)
    pub voice: String,          // 音色名称 (如 "Mia", "苏打", "云希" 等)
    pub clone_sample_id: String,// 复刻参考音频 ID (本地物理文件 handle)
    pub stream: bool,           // 是否启用流式边生成边播报
}
```
> **安全与孤儿处理说明**：`clone_sample_id` 指向本地音频样本。若还原到全新设备且本地缺失该音频文件，发音引擎会安全回退至预置音色，不会引发奔溃。备份还原时向用户提示：“复刻音频属于本地文件，请确认样本已导入”。

## 4. 独立非同步业务表审计

除 `agents` 与 `group_local_settings` 外，数据库中还存在两个纯移动端专属、**未接入 Sync V2 增量管道**的本地持久化数据表：

### 4.1 `model_favorites` (模型收藏表)
- **表结构**：
  ```sql
  CREATE TABLE IF NOT EXISTS model_favorites (
      model_id TEXT PRIMARY KEY,
      created_at BIGINT NOT NULL
  );
  ```
- **现状**：用户在移动端模型选择器（`ModelSelector.vue`）中星标收藏的常用大模型。该列表完全保存在移动端 SQLite 本地，桌面端没有收藏同步接口。
- **备份价值**：高。换机后用户极度需要保留自己常用的 5~10 个大模型置顶列表。

### 4.2 `tarven_rules` (Tarven 上下文规则库)
- **表结构**：
  ```sql
  CREATE TABLE IF NOT EXISTS tarven_rules (
      id TEXT PRIMARY KEY,
      name TEXT NOT NULL,
      rule_type TEXT NOT NULL,
      is_enabled INTEGER NOT NULL DEFAULT 1,
      content TEXT NOT NULL,
      scope TEXT NOT NULL,
      wrap INTEGER NOT NULL DEFAULT 1,
      role TEXT,
      depth INTEGER,
      position TEXT,
      sort_order INTEGER NOT NULL DEFAULT 0,
      created_at BIGINT NOT NULL,
      updated_at BIGINT NOT NULL
  );
  ```
- **现状与内置规则机制**：
  - 物理代码中 `tarven_rules` **未接入 Sync V2**（无同步 DTO、无 hash 计算）。
  - 系统包含两类规则：
    1. **系统预置规则 (Presets)**：`id` 分别为 `"system_meta_injection"`（系统元数据注入）与 `"time_anchoring_v2"`（消息时间线感知），`sort_order = -100`。
    2. **用户自定义规则 (Custom Rules)**：用户在提示词规则界面新建的过滤/世界观/注入规则，`sort_order >= 0`。
- **备份与恢复策略**：
  - **导出**：全量导出用户自定义规则，以及预置规则的启用/禁用开关（`is_enabled`）。
  - **恢复防冲机制**：导入时采用 `INSERT ... ON CONFLICT(id) DO UPDATE`；对预置规则仅覆盖其 `is_enabled` 开关状态，绝不破坏其物理内核的逻辑定义；对自定义规则执行全字段覆盖插入。
- **备份价值**：极高。用户精心编写的角色世界观与提示词强化规则在换机后会完全丢失。将其作为 `standaloneData.tarvenRules` 导出可在空机直接还原。

## 5. 数据库物理表全景与职责分类对照表

| 表名 | 存储内容 | 数据归属渠道 | 是否进入 .vcpcfg | 理由说明 |
|---|---|---|:---:|---|
| `config_domains` | 全局领域配置 (server, voice, jev, navigation 等) | 本机 SQLite | ✅ **是 (`domains`)** | 核心连接、语音、身份与 JEV 参数；需在 `schema.rs:88` 解禁 `navigation` 导出侧栏排序 |
| `agents` | 智能体主表 | **Sync V2 (基础) + 本机 (增强)** | ✅ **提取本地列** | 仅提取 `mobile_system_prompt`, `use_temperature`, `voice_config` |
| `groups` | 群组主表 | **Sync V2** | ❌ 否 | 结构化群组定义由同步带回 |
| `group_members` | 群成员关系表 | **Sync V2** | ❌ 否 | 成员关联由同步带回 |
| `group_local_settings` | 群组本机参数表 | 本机 SQLite | ✅ **是 (`groupPreferences`)** | 群聊运行模式与 JEV 完整参数 |
| `topics` | 话题主表 | **Sync V2** | ❌ 否 | 话题由同步带回（话题置顶键由前端 Pinia 管理） |
| `messages` | 聊天消息主表 | **Sync V2** | ❌ 否 | 聊天历史体积极大，严格归同步 |
| `message_attachments` | 消息附件关联表 | **Sync V2** | ❌ 否 | 归同步 |
| `attachments` | 物理附件元数据表 | **Sync V2** | ❌ 否 | 归同步 |
| `avatars` | 全局多态头像二进制表 | **Sync V2** | ❌ 否 | 头像图片为二进制 BLOB，由同步带回 |
| `model_favorites` | 模型收藏列表 | 本机 SQLite | ✅ **是 (`standaloneData`)** | 纯本地标记常用模型 |
| `model_usage_stats` | 模型调用统计表 | 本机 SQLite | ❌ 否 | 运行时累加统计，换机无需迁移 |
| `tarven_rules` | Tarven 提示词注入规则库 | 本机 SQLite | ✅ **是 (`standaloneData`)** | 用户自定义高级规则，目前不同步 |
| `render_cache` | Markdown AST 渲染缓存 | 本地运行时临时表 | ❌ 否 | 性能加速缓存，启动时按需重建 |
| `active_generations`| 流式会话锁与活跃生成表 | 本地运行时临时表 | ❌ 否 | 运行时防并发锁 |
| `emoticon_library` | 表情包索引库 | 本地资源缓存 | ❌ 否 | 静态内置或本地扫描索引 |
