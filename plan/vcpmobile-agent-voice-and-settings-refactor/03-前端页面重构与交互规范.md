# 03-前端页面重构与交互规范

> 本文档规范 `AgentSettingsView.vue` 的前端重构要求，贯彻「方案 D：微层阶台面式」美学，并对原有模型参数与删除逻辑实施严正保护。

> **交互修订**：仅保留预制音色与音色复刻两种模式；预制只列官方音色，默认“冰糖”；复刻列表保留“无”。关闭独立音色时保留表单并变暗、禁用，实际继承当前已保存的全局配置。移除参考文本；删除声音资产不自动清理任何设置引用，失效 ID 显示为“无”。详见 [05-实施决策与验证记录](05-实施决策与验证记录.md)，其余模型参数与删除 Agent 保护要求保留。

## 1. 布局结构与视觉基准（方案 D: 微层阶台面式）

### 1.1 章节外置头规范
* **纯净小圆点 + 中文主标题**：
  ```html
  <div class="flex items-center gap-1.5 px-0.5">
    <span class="w-1.5 h-1.5 rounded-full bg-blue-500"></span>
    <h3 class="text-xs font-bold text-primary-text">标题名称</h3>
  </div>
  ```
* **严正禁令**：
  * ❌ 严禁出现任何 `// IDENTITY`、`// PROMPT` 等宽英文标签；
  * ❌ 严禁在右侧堆砌装饰性文字（如 `UUID: xxx` 或 `OVERRIDE`）。

### 1.2 台面容器规范 (`plate-container`)
* 边框：`border border-black/10 dark:border-white/10`；
* 圆角：`rounded-lg`（严格遵循方案 D 的 8px 微圆角标准）；
* 背景：`bg-black/[0.03] dark:bg-white/[0.035]` 微弱层阶底色；
* 行间细分隔：`plate-row`（`border-b border-black/5 dark:border-white/5 last:border-b-0`）；
* 注释引导条：`plate-note`（左侧 2px 浅竖线，高密度极简呈现）。

## 3. 音色选择与音色管理组件交互

### 3.1 预置模式 vs 复刻模式的高度对称
* **当前音色行**：
  * 无论是预置模式还是克隆模式，其结构完全一致，右侧带箭头 `>`；
  * 点击该行均呼出轻量弹窗，单选切换当前生效音色。
* **复刻模式特有的音色管理行**：
  * 位于“当前音色”下方，右侧显示已有音色总数；
  * 点击呼出底部半屏抽屉（`drawerCloneManager`）。

### 3.2 音色管理抽屉（Voice Clone Manager Drawer）
1. **列表呈现**：展示本地已注册的声音模型卡片（名称、时长、大小、参考转写文本）；
2. **操作能力**：
   * **选用**：将该模型直接赋给当前 Agent 的 `voice.clone_sample_id`；
   * **试听原声**：播放用户上传的参考音频；
   * **删除**：二次确认后调用 `delete_voice_clone_sample`，并自动清理引用；
   * **上传**：顶部提供「+ 上传新音色」按钮。

### 3.3 上传新音色弹窗（Upload Voice Modal）
* **音色名称**：文本输入框（如“晨光”、“温柔姐姐”）；
* **参考音频选择**：调用移动端原生选择器 `pickFile('file', { maxBytes: 7_000_000 })`，支持 MP3 / WAV；
* **Prompt 参考文本**：多行文本输入，用于录入音频对应的文字，帮助大模型精准对齐音素；
* **确定落盘**：调用 `import_voice_clone_sample`，成功后即刻刷新声音库并自动设为当前选中。

## 4. 严正红线：模型参数与危险区域零变动原则

> [!CAUTION]
> **绝对禁止对以下模块进行逻辑删改**：
> 1. **模型参数配置**：必须 100% 保持原本已有的所有输入项（`model` + `ModelSelector`、`temperature` + `useTemperature` 禁用联动、`contextTokenLimit`、`maxOutputTokens`、`streamOutput`、`useTemperature` 开关）。不准引入滑块替代，不准遗漏任何一个既有设置字段！
> 2. **删除 Agent 单按钮**：由于删除选项仅有这一项，不单独设立「• 危险操作」外置标题或台面外壳，避免冗余设计；直接保留原有的独立单按钮样式（`pt-4 pb-8` 容器，红色半透明细框与透明底色，全宽触控），`handleDelete`、`deleteBlockReason` 拦截文本与二次确认逻辑 100% 保持原样。
