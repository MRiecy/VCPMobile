# vcpmobile-agent-voice-and-settings-refactor

> 本专项工程方案规划 **Agent 设置页面重构（对齐方案 D 微层阶台面式）** 与 **Agent 专属语音解耦全链路改造（前端 + Rust 后端 + SQLite + 移动端沙盒）**。

> **2026-10-28 实施裁决**：用户决定直接硬切，不迁移旧声音目录或前端试验数据；音色模式仅有“预制音色”和“音色复刻”，预制音色默认“冰糖”，“无”仅为复刻音色选项；删除资产不做引用级联，失效引用解析为“无”；关闭独立音色继承当前已保存的全局配置；取消参考文本字段。下列 00–04 为初始设计材料，其中冲突条款由 [05-实施决策与验证记录](05-实施决策与验证记录.md) 取代。实现事实仍以生产代码为准。

## 🎯 核心改造结论备忘

1. **彻底解耦**：全局设置仅保留 API 连接凭据与基础默认音色；每个 Agent 独立管理自身的音色（预置/克隆）、流式与模型；
2. **持久声音资产**：建立多音色本地注册表，只有用户显式删除才移除已登记音色；删除不改写 Agent 或全局配置，失效引用解析为“无”；
3. **平台边界铁律**：双端仅指 Android 与 iOS 移动端沙盒，100% 本地管理，无桌面端同步负担；
4. **美学与已有功能保护**：Agent 设置采用方案 D 纯净外置头与 8px 微圆角台面，模型参数与删除逻辑 100% 保持原样。
