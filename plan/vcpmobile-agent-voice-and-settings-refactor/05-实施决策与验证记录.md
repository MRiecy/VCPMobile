# Agent 语音与设置重构：实施决策

日期：2026-10-28。本文记录本次用户决定及实现导航，不替代生产代码。

## 用户裁决

- 当前为 Debug 开发阶段，不建立旧 `voice-samples` 或试验 `localStorage` 数据兼容、迁移、恢复路径，也不重置整个应用数据库。
- 全局与 Agent 独立音色均增加默认“无”。未启用独立音色时仍继承全局选择；独立选择“无”不会改用全局音色。
- 用户可直接删除克隆资产。删除不扫描、解绑或级联改写 Agent/global 配置；已失效的资产 ID 在界面与朗读解析中视为“无”。用户主动选择“无”才修改自己的草稿。
- “无”没有可用合成声音，不自动换成预置音色。文件损坏、索引损坏及 IO 错误继续如实报错，不冒充未选择。
- 群聊连续朗读跳过“无”音色的成员，继续其他成员；文字生成照常。手动朗读无音色气泡时明确提示不可用。
- 完全删除参考转写文本字段。MiMo 现有克隆请求只使用参考音频，不能把转写文本冒充风格指导；克隆沿用非流式整段合成。
- 保留 ASR、VAD、风格指导、API 连接与全局默认选择。原 Agent 六项模型参数、ModelSelector 和删除拦截逻辑保留。

## 契约修正

- `AgentConfig.voice` 为必有结构，统一默认态，省去 `None` 对象与空 JSON 两套表达；其中 `mode` 可为 `none/builtin/clone`。
- `save_agent_config(agent, baseline)` 返回 `AgentConfig`。共享字段逐项比较，voice 作为同一个配置整体比较，避免交叉合并出用户未选择的音色组合。
- `import_voice_clone_sample(path, name, fileName)`：资产名与原文件名分离，无 `refText`。
- `list_voice_clone_samples`、`get_voice_clone_sample(sampleId)`、`delete_voice_clone_sample(sampleId)`：库记录不因退出页面或切换全局音色自动删除。
- `preview_voice_clone_sample(ttsId, sampleId)`：原声试听走 Rust 播放所有者，不需要 API Key；`stop_tts` 与 `vcp-tts` 事件继续管理真实终态。
- `preview_tts` 仍使用显式草稿；普通气泡读取数据库真实作者，群聊流传递每条消息的 `agentId`，同一消息各分片共享冻结音色。
