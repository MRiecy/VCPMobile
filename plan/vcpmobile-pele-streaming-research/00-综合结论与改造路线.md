# Pele 流式图表：代码级重构方案

2026-10-24。实现范围：消息 AST、fallback 与 stable 图表统一；沿用现有 Rust CodeBlock/TailFrame 输入。固定使用 pele@1.9.0 的 render()，第一次加载共享一个 import Promise，加载后全部同步绘图。

## 1. DOM 契约与 AST / morphdom 双路径

### 1.1 一个宿主，三个固定槽

新增 **src/core/utils/diagramDom.ts**，由 astRenderer 和 astExecutor 共用。宿主身份只认两个 data 属性；mermaid-placeholder 永久保留，成功后可额外加 mermaid，判断逻辑不依赖这两个 class。

~~~html
<div class="vcp-diagram mermaid-placeholder"
     data-content-kind="mermaid" data-mermaid-host="1"
     data-mermaid-source="flowchart LR&#10;A-->B"
     data-mermaid-state="loading" data-mermaid-finalized="false">
  <div data-mermaid-viewport></div>
  <pre data-mermaid-source-view hidden>flowchart LR
A-->B</pre>
  <div data-mermaid-status role="status">图表加载中</div>
</div>
~~~

| 字段/节点 | 写入方 | 内容 |
|---|---|---|
| data-mermaid-source | AST / morphdom / 静态 HTML 生成器 | 最新收到的原始源码 |
| data-mermaid-rendered-source | 图表 controller 成功提交 | 当前 SVG 对应源码；第一次成功前无此属性 |
| data-mermaid-state | controller | loading / streaming / ready / error |
| data-mermaid-finalized | controller | stable 为 true；tail 随消息活动状态更新 |
| viewport | controller | SVG 与全屏装饰，AST 永远不写其后代 |
| source-view | writeDiagramSource | 最新源码；初始隐藏，最终失败显示 |
| status | controller | 加载、生成中、最终错误 |

**diagramDom.ts 的公共接口和关键实现：**

~~~ts
export const DIAGRAM_HOST =
  '[data-content-kind="mermaid"][data-mermaid-host="1"]';

export function isDiagramHost(node: Node): node is HTMLElement {
  return node instanceof HTMLElement
    && node.dataset.contentKind === 'mermaid'
    && node.dataset.mermaidHost === '1';
}

export function renderDiagramHostHtml(source: string): string {
  const s = escapeHtml(source);
  return '<div class="vcp-diagram mermaid-placeholder"'
    + ' data-content-kind="mermaid" data-mermaid-host="1"'
    + ' data-mermaid-source="' + s + '" data-mermaid-state="loading"'
    + ' data-mermaid-finalized="false">'
    + '<div data-mermaid-viewport></div>'
    + '<pre data-mermaid-source-view hidden>' + s + '</pre>'
    + '<div data-mermaid-status role="status">图表加载中</div></div>';
}

function escapeHtml(text: string): string {
  return text.replace(/&/g, '&amp;').replace(/</g, '&lt;')
    .replace(/>/g, '&gt;').replace(/"/g, '&quot;').replace(/'/g, '&#039;');
}

export function createDiagramHost(source: string): HTMLElement {
  const template = document.createElement('template');
  template.innerHTML = renderDiagramHostHtml(source);
  return template.content.firstElementChild as HTMLElement;
}

export function writeDiagramSource(host: HTMLElement, source: string): void {
  if (host.dataset.mermaidSource === source) return;
  host.dataset.mermaidSource = source;
  host.querySelector<HTMLElement>(
    ':scope > [data-mermaid-source-view]',
  )!.textContent = source;
}

export function preserveDiagramMorph(
  from: HTMLElement, to: HTMLElement,
): boolean {
  if (!isDiagramHost(from) || !isDiagramHost(to)) return false;
  const source = to.getAttribute('data-mermaid-source');
  if (source === null) return false;
  writeDiagramSource(from, source);
  // morphdom 将跳过宿主属性，故只显式同步内容定位属性。
  for (const name of ['id', 'data-vcp-key']) {
    const value = to.getAttribute(name);
    if (value === null) from.removeAttribute(name);
    else from.setAttribute(name, value);
  }
  return true;
}

export function normalizeDiagramHosts(root: ParentNode): void;
~~~

normalizeDiagramHosts 的转换规则：顺序查找现有 MERMAID_CONTENT_SELECTOR；跳过标准宿主及其后代、跳过已经含 SVG 的历史节点；其余取 data-mermaid-source 或未渲染 textContent，替换为 createDiagramHost(source)。code.language-mermaid 的替换目标是整个直接父 pre。保留目标 id/data-vcp-key。**同一 helper 同时处理 live 树和待 morph 的 fresh 树**，避免一边有双 marker、一边只有旧 class 导致每帧重建。MERMAID_CONTENT_SELECTOR移至diagramDom，由astRenderer再导出给现有消费者，保持helper单向依赖。

### 1.3 五处 morphdom 使用同一保护规则

在每个 onBeforeElUpdated 的第一行加入：

~~~ts
onBeforeElUpdated(fromEl, toEl) {
  if (preserveDiagramMorph(fromEl, toEl)) return false;
  if (fromEl.isEqualNode(toEl)) return false;
  // 接续该调用点现有的 IMG、VIDEO、AUDIO、焦点分支。
  return true;
}
~~~

返回 false 同时跳过 morphdom 对宿主属性和子树的写入；因此 **先写最新 source，再 return false**。图表原 SVG 留在 viewport，批次完成后 controller 读取更新后的 source。

| 位置 | 修改点 |
|---|---|
| astExecutor.ts:570 morphdomLiveOptions | 加 guard；覆盖 :620 冻结前沿和 :770 patch_raw_html |
| astExecutor.ts:943 replace raw_html/table | 独立 options 同样加 guard |
| astExecutor.ts:1062 replace_inline | 独立 options 同样加 guard |
| useMessageTailRenderer.ts:123 fallback | fresh HTML先进入 detached div、normalize，再交给 morphdom；加 guard |

raw HTML 的 fresh 节点在 repair/filter 后、送入上述四个 AST morphdom 调用前执行 normalizeDiagramHosts；fallback 对解析后的 fresh root执行相同处理。标准 CodeBlock 已直接生成统一宿主。

宿主删除、祖先删除、同 tag 变成普通 div 都允许正常发生。批后 **sweep()** 按整条消息根检查存活性，避免阻止真正删除：

~~~ts

  }

~~~

这里不遍历 tailRoot 来删除全局 entries，否则会误删同消息的 stable 图表。

### 1.4 useMessageTailRenderer：一个批后回调

MessageTailRendererOptions 增加一个同步函数：

~~~ts
onDomCommitted: (root: HTMLElement | null) => void;
~~~

将现有 AST watcher 的同步处理体放进 try/finally；finally 每次读取当前真实根，调用一次。现有 markTailFrameApplied、恢复和提前 return 的条件保持原位置。

~~~ts
try {
  // 原有 sandbox 切换、rebuildSnapshot、reset、applyFrame 处理体。
  // 仅 result.ok 才 markTailFrameApplied；失败继续既有 snapshot 恢复。
} finally {
  const root = useAstForCurrentTail.value ? tailSandboxRef.value : null;
  options.onDomCommitted(root);
}
~~~

fallback watcher 则：

~~~ts
try {
  const fresh = document.createElement('div');
  fresh.innerHTML = options.renderTailHtml(block);
  normalizeDiagramHosts(fresh);
  morphdom(root, fresh, {
    childrenOnly: true,
    getNodeKey: existingGetNodeKey,
    onBeforeElUpdated: preserveDiagramThenExistingMediaRules,
  });
} finally {
  options.onDomCommitted(root);

~~~

finally 覆盖部分应用后失败的帧：已删除宿主需要释放，已写入源码需要协调；帧是否接纳仍由原有 result.ok 判断。空 mutations、snapshot 重建后 return、恢复前清空、sandbox 换位都会经过同一出口。消息组件卸载直接调用 diagrams.dispose()。

## 2. 替代 mermaidRenderer.ts 的同步模块

拆成三处职责：core/utils/diagramDom.ts 管宿主；features/chat/utils/mermaidRenderer.ts 管加载、同步 SVG 和完成缓存；同目录 messageDiagramController.ts 管当前消息的宿主状态。删除旧 Task、Subscriber、pending、queue、running、drain、mermaid.initialize 和 AbortSignal 订阅协议。

### 2.1 渲染模块完整接口

instantiateMermaidSvg 保留当前 ID/marker/aria 引用实例化实现。它的输入是模板，每个气泡和 Viewer 各自实例化。

加载只共享一个 Promise：

~~~ts
let engine: PeleModule | undefined;
let loading: Promise<void> | undefined;

export function isPeleReady(): boolean { return engine !== undefined; }

export function ensurePele(): Promise<void> {
  if (engine) return Promise.resolve();
  if (!loading) {
    loading = import('pele')
      .then(module => { engine = module; })
      .finally(() => { loading = undefined; });
  }
  return loading;
}

export function diagramKey(source: string, p: DiagramLayout): string {
  return JSON.stringify([
    'pele@1.9.0', source, p.maxWidth,
    p.fontFamily, p.fontFamilyMono, p.fontSize,
    p.fontEpoch, p.mathEpoch, p.now,
  ]);
}

export function renderDiagramSync(
  source: string, p: DiagramLayout,
): DiagramAttempt {
  if (!engine) throw new Error('ensurePele must complete before rendering');
  try {
    const result = engine.render(source, {
      maxWidth: p.maxWidth, autoDirection: false,
      fontFamily: p.fontFamily, fontFamilyMono: p.fontFamilyMono,
      fontSize: p.fontSize, math: p.math, now: p.now,
      idPrefix: 'vcp-template',
    });
    return { kind: 'ok', template: {
      key: diagramKey(source, p), source, svg: result.svg,
      width: result.width, height: result.height,
    } };
  } catch (error) {
    return { kind: 'error',
      message: error instanceof Error ? error.message : String(error) };
  }
}
~~~

layout 从挂载宿主的实际宽度与 getComputedStyle读取。now 在创建消息 controller 时取一次，fontEpoch 在字体加载完成时递增，mathEpoch 随 resolver 变化递增；这些值在 tail 与 stable 间共用。颜色不进入几何 key，使用 --pele-* 变量。

readCompleted/rememberCompleted 使用现有4 MiB总量、512 KiB单项上限；entry字节数按 (key.length + svg.length) * 2估算。更新同 key先减去旧bytes，读取时移到Map末尾，写入前从Map头逐项淘汰。**只有 finalized 且成功的 template进入此缓存**，streaming前缀只存在宿主的lastGood字段。

### 2.3 核心更新与错误流转

~~~ts
function syncRoot(root: HTMLElement, finalized: boolean): void {
  if (disposed) return;
  options.prepareStyles();
  normalizeDiagramHosts(root);

  const hosts = [
    ...(isDiagramHost(root) ? [root] : []),
    ...root.querySelectorAll<HTMLElement>(DIAGRAM_HOST),
  ];
  for (const host of hosts) {
    if (!options.getRoot()?.contains(host)) continue;
    const source = host.dataset.mermaidSource ?? '';
    let entry = entries.get(host);
    if (!entry) {
      entry = { host, latestSource: source, finalized };
      entries.set(host, entry);
    } else if (source !== entry.latestSource) {
      entry.latestSource = source;
      entry.loadError = undefined;
    }
    entry.finalized = finalized;
    host.dataset.mermaidFinalized = String(finalized);
    flushEntry(entry);
  }
  sweep();
}

function flushEntry(entry: Entry): void {
  const host = entry.host;
  if (disposed || !options.getRoot()?.contains(host) || !isDiagramHost(host)) return;
  if (!isPeleReady()) {
    present(entry);
    requestEngine();
    return;
  }

  entry.loadError = undefined;
  options.decorate(host); // 先建立固定wrapper，宽度从始终参与布局的host计算
  const layout = options.readLayout(host);
  if (layout.maxWidth <= 0) return; // 展开/resize后 refreshLayout
  const key = diagramKey(entry.latestSource, layout);
  if (entry.lastAttempt?.key !== key) {
    const reused = readCompleted(key)
      ?? promotionTemplates.find(template => template.key === key);
    const result = reused
      ? { kind: 'ok' as const, template: reused }
      : renderDiagramSync(entry.latestSource, layout);
    entry.lastAttempt = { key, result };

    if (result.kind === 'ok') {
      const view = host.querySelector<HTMLElement>(
        ':scope > [data-mermaid-viewport]',
      )!;
      const fragment = document.createElement('template');
      fragment.innerHTML = instantiateMermaidSvg(result.template.svg);
      const nextSvg = fragment.content.firstElementChild as SVGSVGElement;
      const wrapper = view.querySelector<HTMLElement>(':scope > .vcp-mermaid-wrapper')!;
      const currentSvg = wrapper.querySelector(':scope > svg');
      if (currentSvg) currentSvg.replaceWith(nextSvg);
      else wrapper.append(nextSvg);
      entry.lastGood = result.template;
      host.dataset.mermaidRenderedSource = result.template.source;
      options.decorate(host);
    }
  }

  if (entry.finalized && entry.lastAttempt?.result.kind === 'ok') {
    rememberCompleted(entry.lastAttempt.result.template);
  }
  present(entry);
}

function present(entry: Entry): void {
  const { host, finalized, lastGood, lastAttempt, loadError } = entry;
  const view = host.querySelector<HTMLElement>(':scope > [data-mermaid-viewport]')!;
  const source = host.querySelector<HTMLElement>(':scope > [data-mermaid-source-view]')!;
  const status = host.querySelector<HTMLElement>(':scope > [data-mermaid-status]')!;
  const failed = lastAttempt?.result.kind === 'error' ? lastAttempt.result.message : undefined;
  const finalError = loadError ?? (finalized ? failed : undefined);

  if (finalError) {
    host.dataset.mermaidState = 'error';
    view.hidden = true;
    source.hidden = false;
    status.textContent = '图表渲染失败：' + finalError;
  } else if (!isPeleReady()) {
    host.dataset.mermaidState = 'loading';
    view.hidden = !lastGood;
    source.hidden = true;
    status.textContent = '图表加载中';
  } else {
    host.dataset.mermaidState = finalized ? 'ready' : 'streaming';
    view.hidden = !lastGood;
    source.hidden = true;
    status.textContent = finalized ? '' : '图表生成中';
  }
  host.classList.toggle('mermaid', !!lastGood && !view.hidden);
}
~~~

流式失败时只更新lastAttempt，lastGood和viewport保持原值。下一段修复源码后，key改变，重新render并原子替换SVG。相同非法源码进入finalized时复用已记录的解析错误、直接翻转error UI；若闭围栏后的source变化，则对新source同步render一次。

~~~mermaid
stateDiagram-v2
  [*] --> loading
  loading --> streaming: 加载完成 / 活动源
  loading --> ready: 加载完成 / 封存源合法
  loading --> error: 加载失败或封存源非法
  streaming --> streaming: 新源合法 / 更新SVG
  streaming --> streaming: 新源非法 / 保留lastGood
  streaming --> ready: finalized / 最新源合法
  streaming --> error: finalized / 最新源非法
  error --> ready: 新封存源修正
  error --> streaming: 新活动源修正
~~~

一次模块加载结束后重新读取当前DOM和source，不捕获请求发起时的旧source：

~~~ts
function requestEngine(): void {
  if (loadRequested || disposed) return;
  loadRequested = true;
  void ensurePele().then(() => {
    if (disposed) return;
    options.prepareStyles();
    sweep();
    for (const entry of entries.values()) {
      entry.latestSource = entry.host.dataset.mermaidSource ?? '';
      entry.finalized = entry.host.closest('[data-message-render-region]')
        ?.getAttribute('data-message-render-region') === 'stable'
        || options.isTailFinalized();
      entry.loadError = undefined;
      flushEntry(entry);
    }
  }).catch(error => {
    if (disposed) return;
    sweep();
    for (const entry of entries.values()) {
      entry.loadError = error instanceof Error ? error.message : String(error);
      present(entry);
    }
  }).finally(() => { loadRequested = false; });
}

function capturePromotionTemplates(): void {
  promotionTemplates = [...entries.values()]
    .flatMap(entry => entry.lastGood ? [entry.lastGood] : []);
}
function releasePromotionTemplates(): void { promotionTemplates = []; }

function syncStableRegions(): void {
  const root = options.getRoot();
  if (!root || disposed) return;
  for (const region of root.querySelectorAll<HTMLElement>(
    '[data-message-render-region="stable"]',
  )) syncRoot(region, true);
  sweep();
}

function getRendered(host: HTMLElement): RenderedDiagram | null {
  const entry = entries.get(host);
  const view = host.querySelector<HTMLElement>(':scope > [data-mermaid-viewport]');
  const svg = view?.querySelector<SVGSVGElement>(':scope > .vcp-mermaid-wrapper > svg');
  if (!entry?.lastGood || !svg || view?.hidden
      || !options.getRoot()?.contains(host)) return null;
  return { svg, renderedSource: entry.lastGood.source };
}

function refreshLayout(): void {
  if (disposed) return;
  options.prepareStyles();
  sweep();
  for (const entry of entries.values()) flushEntry(entry);
}

function dispose(): void {
  disposed = true;
  entries.clear();
  promotionTemplates = [];
}
~~~

sweep实现见1.3。controller工厂返回接口列出的8个方法。消息层一个ResizeObserver观察内容列；宽度变化、折叠展开以及fontEpoch变化调用refreshLayout，卸载断开observer并dispose。

## 3. tail → stable 同帧交接与消费端改动

### 3.1 把promotion安排在Vue已有pre/post两阶段

MessageRenderer.vue:636现有pre watcher中，在任何动画判断之前插入：

~~~ts
if (blocks === previousBlocks) return;
diagrams.capturePromotionTemplates(); // 旧tail尚未被Vue删除
pendingStableRevealBlocks = new WeakSet();
// 继续原有文字动画逻辑。
~~~

promotionTemplates只保存lastGood引用，大小上限等于这条消息当时的图表数。随后tail reset即使sweep删除了旧Entry，引用快照仍存在；稳定post结束清空。完成缓存保存完整图，Entry保存每宿主最近成功图，promotion保存一个Vue更新批次的交接引用，三者各有明确释放点。

~~~text
同一轮Vue更新
  pre：捕获旧tail的lastGood模板
  patch：旧tail移除；stable v-html生成标准loading宿主
  post：同步注入消息CSS → 精确key命中模板或同步render → 写入SVG
  post结束：清空promotion模板
  浏览器绘制：stable宿主已是SVG
~~~

命中顺序为completedLRU → promotionTemplates → 同步render。key包含**原始source与完整布局输入**，不按block hash、AST t0或bubble index猜配。闭围栏导致source或宽度不同，直接同步重画；不会为了等cache而排到下一帧。

Vue当前运行时的post回调由flushJobs在同一Promise微任务里同步执行。故零源码闪屏的条件是：**图表post过程没有await、没有RAF、没有异步队列**。tail已画出过图说明Pele已加载；首次冷加载则保持HTML一开始就生成的loading槽，源码hidden。

### 3.5 复制SVG与PNG共用样式固化函数

新增到 **src/core/utils/renderedImageExport.ts**：

~~~ts
export function cloneSvgWithComputedStyles(source: SVGSVGElement): SVGSVGElement;
export function serializeDisplayedSvg(source: SVGSVGElement): string {
  return new XMLSerializer().serializeToString(cloneSvgWithComputedStyles(source));
}
~~~

cloneSvgWithComputedStyles在connected源DOM读取每个对应元素的getComputedStyle，只修改clone：

~~~ts
const EXPORT_PROPERTIES = [
  'color', 'fill', 'fill-opacity', 'fill-rule',
  'stroke', 'stroke-width', 'stroke-opacity', 'stroke-dasharray',
  'stroke-dashoffset', 'stroke-linecap', 'stroke-linejoin', 'stroke-miterlimit',
  'opacity', 'font-family', 'font-size', 'font-style', 'font-weight',
  'letter-spacing', 'word-spacing', 'text-anchor', 'dominant-baseline',
  'paint-order', 'stop-color', 'stop-opacity',
  'marker-start', 'marker-mid', 'marker-end', 'clip-path', 'mask', 'filter',
] as const;

export function cloneSvgWithComputedStyles(source: SVGSVGElement): SVGSVGElement {
  if (!source.isConnected) throw new Error('图表已离开页面');
  const window = source.ownerDocument.defaultView;
  if (!window) throw new Error('图表窗口不可用');
  const copy = source.cloneNode(true) as SVGSVGElement;
  copy.setAttribute('xmlns', 'http://www.w3.org/2000/svg');
  const originals = [source, ...source.querySelectorAll('*')];
  const clones = [copy, ...copy.querySelectorAll('*')];
  const ids = new Set(originals.map(el => el.id).filter(Boolean));
  const documentUrl = new URL(source.ownerDocument.URL);
  documentUrl.hash = '';

  for (let i = 0; i < originals.length; i++) {
    const style = window.getComputedStyle(originals[i]);
    const target = clones[i] as SVGElement | HTMLElement;
    if (!target.style) continue;
    for (let j = 0; j < style.length; j++) {
      const property = style.item(j);
      if (property.startsWith('--pele-')) {
        target.style.setProperty(property, style.getPropertyValue(property), 'important');
      }
    }
    for (const property of EXPORT_PROPERTIES) {
      let value = style.getPropertyValue(property);
      if (!value) continue;
      value = value.replace(/url\(\s*["']?([^"')]+)["']?\s*\)/g, (original, href) => {
        try {
          const url = new URL(href, source.baseURI);
          const id = decodeURIComponent(url.hash.slice(1));
          url.hash = '';
          return ids.has(id) && url.href === documentUrl.href
            ? 'url("#' + encodeURIComponent(id) + '")' : original;
        } catch { return original; }
      });
      target.style.setProperty(property, value, 'important');
    }
  }
  return copy;
}
~~~

getComputedStyle已解析CSS变量和classDef颜色，内联最终值即可；url(#marker)只在本SVG确有ID且同document时本地化。保留现有几何属性、transform、viewBox和ID；不把所有computed CSS机械复制进SVG。

上述URL片段采用百分号编码。同步修改instantiateMermaidSvg的两处ID查找，使历史arrow:head等ID进入Viewer时仍能重写引用：

~~~ts
const resolveId = (fragment: string): string | undefined => {
  try { return ids.get(decodeURIComponent(fragment)) ?? ids.get(fragment); }
  catch { return ids.get(fragment); }
};
// 原url(...)回调中：
const replacement = resolveId(id);
return replacement ? start + '#' + replacement + end : value;
// 原href属性分支中：
const replacement = attr.value.startsWith('#')
  ? resolveId(attr.value.slice(1)) : undefined;
~~~
