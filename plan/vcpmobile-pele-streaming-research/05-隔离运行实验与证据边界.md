## 1. 直接用于状态机的观察

| 输入 | render结果 | controller处理 |
|---|---|---|
| flowch | unsupported-diagram | 活动期保持loading/streaming呈现 |
| flowchart LR下A[ | syntax | 保留lastGood |
| 完整节点后接半条箭头 | syntax | 保留lastGood |
| subgraph/sequence loop缺end | syntax | 等source后续更新 |
| 完整边，不含末尾换行 | 成功 | 当次提交SVG |
| 相同完整边加换行 | 成功，SVG hash相同 | key按原始source区分；未命中同步render |
| 50,001字符，默认limit | limit | 封存后error+源码 |
