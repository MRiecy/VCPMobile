# VChat 渲染新增能力与 VCPMobile 对照审计

审计日期：2026-10-24（Asia/Shanghai）。范围：消息渲染、流式显示、富内容执行、工具协议和与它们直接相关的交互；保存于 `plan/vcpchat-rendering-capability-audit-20261024/`。

## 1. 本轮最重要的结论

移动端已有稳定区/活动尾部、Rust AST diff、增量代码高亮、raw HTML 冻结前沿、KaTeX/Mermaid、SVG/MathML、完整 HTML 脚本沙盒和恢复身份链。后续应在这套基础上补齐内容语义和独立运行时，不需要整体换掉流式架构。

桌面在最近一轮移动流式深化后，最有价值的增加集中在：**Pixi v8 动画岛、JEV 自然语言工具卡、严格工具结果域、结果上下文隐藏/恢复、工具多种呈现与按需挂载**。10 月 24 日远端又增加了 **Pele 图表后端替换** 和 **消息内嵌 v 图表 v2**。本地桌面尚未含后两项，本报告已另读远端固定提交补齐。

移动最值得优先补的差异是 **CSS 作用域语义、工具结果嵌套/域优先级与 HIDDEN 读取语义、JEV 卡片、Markdown 结构字段**。它们影响现有消息的正确表达及后续上下文；图表资产与动画运行时适合后续独立专题。

两个关键纠偏：**MoonAST/MoonAST V2 属于 ProjectForge 源码索引，不是消息渲染引擎；Pele 是图表渲染库，不是流式消息引擎。** 主代理初读提交标题时曾把 MoonAST 归入渲染，已通过实际文件 diff 和调用链纠正，本报告采用纠正后的结论。

## 5. 不应列入当前移植清单的项目

- **MoonAST/MoonAST V2**：源码索引/工程理解技术，不在消息渲染主链。
- **`<!--brk-->` 桌面连续气泡**：曾在 6 月增加，7 月移除；移动仍有自己的分条能力。
- **工具结果真删除**：已被 HIDDEN 可逆上下文排除替代，当前旧函数名不能定义行为。
- **full/steady/once 气泡流光设置**：远端中间提交曾增加，最终源码已退场；今日默认工具样式已弱化装饰。
- **脚注、学术引用、任意图表 fence**：本次没有确认两端普遍支持；普通链接/HTML 能承载并不构成专用语法。
- **独立 Chart、Scriptorium、阅读器能力**：只有沿调用链进入消息的部分才算消息能力；今日 chart embed 已满足这个条件，其余仍分别记账。

六位子代理并行完成分项审计，主代理补查远端、跨篇校核并整合。本次证据包括：

1. 两仓当前源码调用链、字段和生命周期审查；Git 历史按实际 diff 定位，保留固定 SHA。
2. 桌面 bundled Marked/highlight.js/KaTeX 的局部 Node 读取/输入解析，确认库版本、实际语言表和 Markdown 结构输出；不代表完整 Electron 入口通过。
3. 两端当前 CSS 作用域函数的只读 host 执行，确认特定输入生成的 CSS；不代表浏览器布局或性能结果。
4. 上游固定范围 compare、远端新增生产文件读取；`moveBefore` 官方说明与兼容数据核对。
5. 九份报告共 475 个本地文件/源码链接已核验目标存在；带行号的链接同时检查未超出文件范围。这只证明引用位置可访问，不把链接计数当作行为验证。
