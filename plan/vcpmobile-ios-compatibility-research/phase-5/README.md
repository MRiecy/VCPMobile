## 2026-10-18：iOS 原生职责整理与复审

基线为 `83a77c5a`。用户批准保留主插件单一 SwiftPM target 和独立 Share Extension，先修取消/终态，再按功能归目录。当前源码导航见 [插件局部索引](../../../src-tauri/plugins/vcp-mobile/AGENTS.md) 和 [插件总览](../../../docs/plugins/00_总览与导航.md)。

- 主插件按 Lifecycle、Files、Media、Device、WebView、Notifications、Background、Sharing、Clipboard、Haptics 组织；根入口 322 → 50 行。事件订阅整体提取，保留单一长期 Channel、进程序列和替换 generation；36 个命令 selector 的名称与签名保持。
- Files 分离选择、对外交付、流式 IO 和真实共享结果类型。普通 Files 与配置备份共用可取消协调；呈现操作保存初始弱 Scene 身份，断开清理不再依赖当时的 WebView window。系统读取中的文件继续等真实终态释放。
- Share Extension 分为 UI、获取与槽位存储。获取 owner 统一裁决成功/失败/取消，provider 读取排空后才提交终态并释放 lease；成功提交不会被迟到取消覆写。复审补齐扩展内部协调等待的取消，provider Progress 与 NSFileCoordinator 分别持有，锁外执行取消。
- 独立网络查询与恢复遮罩按职责提取；相机、图片、音视频、传感器、通知和后台资源状态机保持原 owner。扩展工程输入从实际 Swift 文件收集同一份复制/编译清单，主应用只嵌入扩展。

主代理和四位子代理完成交叉源码复审，覆盖 selector/DTO、Swift 访问范围、Channel/观察者、Scene 断开、provider 借用 URL、媒体结果交付、后台租约、跨进程文件锁与 lease。没有修改 Rust/Vue 协议、SwiftPM target、部署版本、系统权限或 workflow。

## 输入

Phase 2 native 接入、Phase 3 attempt/terminal/settle 契约；与 Phase 4 可按依赖并行。

## 既定范围

最低 iOS/iPadOS 26.0 下的 SSE 静音音频租约、系统中断与资源释放；同步和预渲染刷新的前台常亮；其他连接和维护工作沿原 owner 尽力执行及收尾；单次业务终态。不接入 continued task，不新建独立 helper 或后台业务缓存。

产品输入沿用 [D1–D19，含最新 D2](../09-Magi综合裁决与待决策清单.md)，依赖顺序见 [总路线](../08-分期实施路线图与验收门禁.md)。历史的严格后台要求与 continued-task 候选已由上述用户决定调整；验收证据仍单独记录。

## 获批任务与依赖

| 任务 | 入口与实施内容 | 依赖与完成条件 |
|---|---|---|
| P5-1 SSE 方案选择 | 用户已选择原生循环静音音频，以尽力支持现有 Rust SSE 接收；音频只归 Stream 任务 | 不承诺独立进程存活或系统持续调度；系统停止、音频中断和网络失败均保留真实结果 |
| P5-2 attempt 与终态 | 同一 attempt/task/generation 绑定、取消原因、settle receipt、真实字节/字符/可选 token 与持久化提交 | 依赖 Phase 3 业务收尾；完成、取消、系统结束、网络错误共享单次终态，不用后台层新发请求或伪造进度 |
| P5-3 音频 adapter | 一个进程级 Swift owner 持有播放资源，显式任务租约聚合，处理中断、路由变化、媒体服务重置与最终释放 | 无循环自动重试、无重新发送生成请求；普通中断不作为业务错误，真实激活或复播失败沿现有通知链告知；不要求麦克风或音频输入权限 |
| P5-4 常亮及其他后台工作 | 仅 Sync/Prerender 租约请求前台常亮；Log/Sync/Distributed/维护沿现有用途尽力继续或关闭 | 最后一个常亮租约结束后恢复 idle timer，后台不强制亮屏；这两类任务不自行申请音频，聊天不申请常亮 |

如采用音频相关方案，需同时交代会话抢占、系统中断、路由变化、资源结束与用户可感知行为；不以“没有可听声音”推断执行权永久存在。系统声明与资源加入的依据来自最终选定方案，不能先堆叠后台模式。

## 当前实施与后续工作

选择已经由用户确认，原请求身份、取消和持久终态继续归 Rust。兼容复审中的附件路径/GC、缓存缺失、原生取消和前端输入问题与本轮一起修复，具体边界见 03；后续集中进行检查、测试和固定 Apple 工具链构建。

## 完成条件

显式任务租约与原业务终态保持一致；获取失败、中断、正常结束和取消均有对应资源处理；无请求时音频和任务常亮均释放。仅声明实际使用的 audio 后台模式。源码审查、后续编译结果及未验证的后台行为分别记录，并入 G2；不将静音播放或常亮表述成严格后台保证。
