## 运行时平台重构（2026-10-09 历史交付）

按用户决定，以 Vue 运行时分支表达功能差异，移除以防绕过为目的的重复能力门禁。六位子代理分工实施并交叉复审，主代理集成；长期约定见跨平台规范。以下是该次交付快照：其后 [Phase 3](../phase-3/README.md) 已接入通知/设备/Distributed 源码，因此下列当时的未接入状态不是当前结论。

- 平台身份统一进入 [platform.ts](../../../src/core/utils/platform.ts)：使用 `plugin-os 2.4.0` 同步信息，普通 Vite 预览无原生平台。两端锁文件只增加该插件所需依赖，现有 Tauri 版本未升级。
- 删除 app Rust 的 `platform.rs`、前端能力 Store/类型、旧查询命令，以及 Swift 能力 DTO、查询和专属超时槽。启动不再等待能力查询；系统权限、生命周期/网络事件及事件注册最终结果仍由原所有者处理。
- 删除通用 Rust 能力门禁。Distributed 未接通平台的启动选择集中到现有调和入口；读取配置、状态和停止清理不受整项拒绝。APK 安装只走 Android 安装器，不再用非 Android fallback 打开 APK。
- iOS 更新、Root、语音、缓存保留说明；对应原生动作不启动。Distributed 可查看和保存配置，节点运行及设备工具尚未接入。配置读取完成前禁止保存，失败可重试，保存成功反馈只由 Settings Store 产生。
- 清除能力表镜像测试，保留真实权限、恢复、取消与 R3 重放验证。共同权限外壳已整理，当前 iOS 无已接入权限项目时直接继续启动；真实授权、文件/媒体、分享/通知、设备工具和后台专项仍按各自阶段适配。
