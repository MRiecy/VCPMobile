## 既定范围

手动 Actions G2 release device archive；Mach-O/依赖/plist/资源结构检查；.app.zip、条件性 .unsigned.ipa、manifest/SHA-256 与用户签名说明。

通知、相机/照片、双向分享和最终后台方案新增的用途声明、扩展 target、资源、entitlement 与 Bundle ID 关系也属于本阶段集成范围。incoming share 如需 Extension/共享容器，自签说明须覆盖主应用与扩展的实际约束；不能仅改主 app identifier 即宣称全部可安装。APNs、正式签名与付费 Team 未因系统通知获批自动获得授权。

产品输入沿用 [D1–D19](../09-Magi综合裁决与待决策清单.md)，依赖顺序见 [总路线](../08-分期实施路线图与验收门禁.md)。本入口是工作区索引，不表示本阶段已实施。

## 启动时的第一项工作

该阶段计划核对 runner 的 Xcode/SDK、最终主应用和扩展 ID、entitlement 及任务前缀之间的对应关系。

在本目录新增阶段子规划、逐路径任务、验证与交接记录。每条任务列出生产入口/owner、输入输出、异常/取消、资源释放、依赖、验证方法；以代码恢复现状，不从旧计划反推实现。

## 完成条件

产物与审计指向相同 commit/输入；通知/分享/媒体/后台对应的真实系统声明和扩展资源随产物审查；打包和自签输入可核对，未解决的后台条件或自签限制明确交付。发布动作另遵循用户授权，项目不建设 iOS 实机体系。

操作入口见 [iOS 构建说明](../../../docs/IOS_BUILD.md)，阶段记录只登记对应提交实际取得的构建或运行证据。
