## 输入

最低 iOS/iPadOS 26.0，构建使用固定 Xcode 26.2。Vue 管理用户意图和显示，Rust 管理文件/分享业务与持久提交，Swift 管理系统资源。接口和目录按这些职责设计；系统授权、用途说明与结果反馈随具体操作交付。

## 既定范围

Files/PHPicker/security scope/staging/ImageIO/CAS、拍照、相册保存、图片发送转换、文件预览/导出、incoming/outgoing share、上传取消；WebKit 缓存、CSS、Insets、键盘、选择、弹层和窗口布局。

产品输入沿用 [D1–D19](../09-Magi综合裁决与待决策清单.md)，依赖顺序见 [总路线](../08-分期实施路线图与验收门禁.md)。源码接入、目标构建和原生运行各自具有独立证据范围。
