# 00. 研究契约与证据账本

## 1. 研究目标

本专项回答四个问题：

1. 当前 VCPMobile 哪些架构和能力可以复用到 iOS/iPadOS；
2. 哪些 Android 语义必须改造、降级或永久不提供；
3. 在没有 Mac 和 iOS 设备的情况下，最多能证明到什么程度；
4. 真正施工前需要用户和项目负责人冻结哪些产品、平台与发布决策。

本轮输出是**研究与决策资料**，不是 iOS 实现。没有生成 Apple 工程，没有添加 Swift，没有改变当前 Android-only 产品契约。

## 2. 范围与非目标

### 范围内

- Vue 3/WebKit 的布局、渲染、键盘、安全区、手势与可访问性；
- Rust/Tauri 的 target、cfg、状态 owner、文件/数据库/网络依赖；
- `tauri-plugin-vcp-mobile` 41 条公开命令及隐藏原生调用面；
- Chat、Sync、Distributed、更新和生命周期的 iOS 语义；
- Apple 权限、后台执行、局域网、ATS、隐私清单、签名、TestFlight/App Store；
- Linux 静态检查、macOS build、Simulator、真机和审核的分级门禁。

### 范围外

- 本轮不修改生产代码、测试、CI 或长期规范；
- 不生成 `src-tauri/gen/apple`；
- 不假定 PWA 是低成本替代；
- 不使用私有 API、越狱能力或审核规避方案；
- 不在没有设备证据时承诺 WebKit、后台、相机、音频、局域网或内存表现；
- 不为 iOS 新建平行 Vue 应用、平行数据库、平行 Chat/Sync 状态机。

## 3. 证据等级

| 等级 | 证据 | 能证明 | 不能证明 |
|---|---|---|---|
| E0 设计推导 | 官方文档 + 当前源码 | 平台规则、调用链、明显缺口、候选架构 | 编译或运行 |
| E1 Linux 静态 | `rg`、配置解析、Cargo target 依赖图、TS/Rust host tests | cfg/依赖是否可解析、契约测试是否自洽 | Apple SDK 编译、Swift binding、WKWebView 行为 |
| E2 macOS 编译 | 完整 Xcode、Apple Rust targets、SwiftPM/CocoaPods、`xcodebuild` | Rust/Swift 编译链接、生成树、Simulator artifact | 真机权限、后台冻结、物理传感器 |
| E3 Simulator | 具名 Xcode/iOS runtime + iPhone/iPad 模拟器 | 启动、基础 IPC、窗口尺寸、旋转、部分键盘/safe area | 相机/麦克风质量、真实局域网权限、jetsam、真实后台行为 |
| E4 真机 | 具名 iPhone/iPad、系统版本、构建 SHA | 物理权限、网络、手势、后台、内存、媒体、扩展 | App Store 审核和生产分发 |
| E5 分发链 | 签名归档、App Store Connect、TestFlight、App Review | 仅能按 `uploaded → processed → internal beta → external beta → approved → released` 的实际子状态声明分发、签名、隐私或审核结论 | 所有未来设备/系统版本都无回归；低级子状态不能证明高级子状态 |

证据等级只能逐级升级，不能跨级替代。例如：

- `cargo tree` 成功不是 `cargo check --target aarch64-apple-ios`；
- Safari 页面正常不是 Tauri WKWebView IPC 正常；
- Simulator 启动不是 Local Network、APNs、相机或后台已验收；
- TestFlight 可安装也不是 App Review 已通过。

### 4.2 当前主机事实

```text
OS: Linux x86_64
rustc: 1.97.1
已安装 Rust targets: Android 4 ABI + x86_64 Linux
xcodebuild/xcrun/simctl/swift/pod: NOT_FOUND
pnpm tauri ios --help: unrecognized subcommand 'ios'
```

这与 Tauri 官方要求一致：iOS 开发需要 macOS、完整 Xcode、Apple Rust targets 和 CocoaPods。这里的 `unrecognized subcommand` 只证明当前 Linux host/CLI 的平台门控，不能据此声称仓库 iOS 配置损坏。参见 [Tauri Prerequisites](https://v2.tauri.app/start/prerequisites/)。

### 4.3 本轮唯一 Apple target 动态检查

```text
cargo tree --locked --manifest-path src-tauri/Cargo.toml \
  --target aarch64-apple-ios -e normal --depth 1
```

命令成功解析了当前直接依赖，包括 Tauri、SQLite、reqwest/rustls、tokio-tungstenite、自定义插件等；JNI 没有进入 Apple target 依赖面。

严格解释：

- 可以声称：`Cargo.lock` 与 cfg 在依赖图层面未立即拒绝 `aarch64-apple-ios`；
- 不可声称：任何 crate 已通过 Apple SDK 编译、链接、运行或 App Store 审核；
- 下一有效证据必须来自 macOS 上的 Apple target check 和 Xcode build。

## 5. 官方约束账本

以下仅使用 Tauri 和 Apple 官方资料作为平台结论依据。

### Tauri

- [iOS 前置条件](https://v2.tauri.app/start/prerequisites/)：macOS、完整 Xcode、Apple Rust targets、CocoaPods。
- [移动插件开发](https://v2.tauri.app/develop/plugins/develop-mobile/)：iOS 侧使用 Swift `Plugin`、`@objc` commands、Swift Package 和插件 binding。
- [iOS 签名](https://v2.tauri.app/distribute/sign/ios/)：App ID、证书、provisioning profile、自动或手动签名。
- [App Store 分发](https://v2.tauri.app/distribute/app-store/)：`tauri ios build`、签名 IPA、App Store Connect/TestFlight。
- [WebView 版本](https://v2.tauri.app/reference/webview-versions/)：iOS 使用系统 WKWebView/WebKit，能力随 OS 更新。

### Apple 后台与网络

- [Choosing Background Strategies](https://developer.apple.com/documentation/backgroundtasks/choosing-background-strategies-for-your-app)：后台策略必须匹配明确用途。
- [Configuring Background Execution Modes](https://developer.apple.com/documentation/Xcode/configuring-background-execution-modes)：App 通常在后台被挂起，后台模式应最小使用。
- [URLSession](https://developer.apple.com/documentation/foundation/urlsession)：background session 适合文件上传/下载，不是持续 SSE 的通行证。
- [TN3179 Local Network Privacy](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)：局域网首次访问授权、Info.plist 说明和 denied 处理。
- [ATS](https://developer.apple.com/documentation/security/preventing-insecure-network-connections)：默认要求安全连接，例外必须收窄并说明。

### Apple 隐私、能力与发布

- [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)：公开 API、自包含、沙箱和合法后台用途。
- [Privacy Manifest Files](https://developer.apple.com/documentation/bundleresources/privacy-manifest-files)：`PrivacyInfo.xcprivacy` 与第三方 SDK 隐私声明。
- [User Notifications](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications)：在上下文中请求本应用通知权限。
- [Document Picker](https://developer.apple.com/documentation/uikit/uidocumentpickerviewcontroller)：Files 选择和外部文档 URL。
- [Photo Library](https://developer.apple.com/documentation/photos/phphotolibrary)：照片库权限与写入。
- [UIActivityViewController](https://developer.apple.com/documentation/uikit/uiactivityviewcontroller)：outgoing share；iPad 必须使用合适 popover 呈现。
- [Share Extension](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/Share.html)：incoming share 是独立 extension target。

## 6. 推导纪律

文档使用下列词义：

- **可复用**：设计或代码有复用价值，不等于零修改可编译；
- **理论可行**：存在公开 API/框架路径，尚无本项目构建或运行证据；
- **近似等价**：用户目标相近，但 DTO、生命周期或限制必须改变；
- **降级**：能力范围缩小且 UI 必须解释；
- **不支持**：平台无安全等价，必须 fail-closed，不能返回模拟成功；
- **阻断**：在进入下一阶段前必须关闭；
- **验收**：只用于已经取得相应 E2–E5 证据的结论。
