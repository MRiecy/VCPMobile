增量 AST Diff 渲染引擎

Rust 后端解析流式 Markdown 为 AST，与上一帧递归 diff，产出最小化 AstMutation 指令集。前端通过 Node Registry 精确命中目标 DOM 节点，执行手术级操作——从 appendData(chunk) 到 replaceChild——从不触碰兄弟节点。

8 种突变指令 Epoch / Revision 双级时序 四级替换策略 morphdom 局部 diff rustc_hash::FxHasher

RAG 灵视中心

全新认知广播观察器。WebSocket 连接桌面 VCP，实时监听 6 类 AI 认知事件：知识库检索、元思考链、记忆取回、Agent 梦境周期。zstd 压缩缓存（500 条 FIFO），前端频谱动画 Canvas。

工具调用摘要

ToolCallSummary 块类型自动识别引擎。中英文关键词匹配 7 种 工具结果状态（success / rejected / failure / timeout / cancelled / skipped / unknown），前端颜色编码玻璃态卡片。

工具审批系统

高风险工具操作触发审批通知（不自动消失），用户输入理由（1000 字限制），通过 VCPLog WebSocket 发送批准/拒绝响应。安全可控的人机协作模式。

划词助手

从任意上下文创建独立对话：传入临时消息列表，自动以时间命名新话题，批量写入消息与 AST 渲染块，异步触发 AI 标题生成。

历史 & 搜索优化

分页加载 + rAF 30Hz 批量刷新 + 滚动锚点四场景状态机。AbortController 并发安全。虚拟滚动话题列表，双层过滤搜索，标签切换自动清空。
