# MiMo 语音风格控制

根据 MiMo 官方风格控制说明整理。

支持在一段语音中切换风格、混合情绪，也可从整段基调细化到句子节奏、词语重音和单字的拖音、气音。

## 1. 自然语言控制

用自然语言描述想要的声音：**声线、语速、气息、停顿和情绪**。可以组合多种感受，例如“压抑的愤怒”“带着哽咽的笑意”“温柔但疲惫”。

> 用轻快上扬的语调向领导报喜，语速稍快，带着查到成绩后压抑不住的激动与小骄傲，声音明亮有活力。

### 导演模式

需要更精细的表演时，可从三个维度描述：

- **角色**：人物身份、性格、气质与说话习惯。
- **场景**：发生了什么、和谁说话、当下的情绪与对方反应。
- **指导**：语速、气息、停顿、重音、共鸣、音色与情绪起伏。

适用于角色配音、影视级内容生成等对演绎要求较高的场景。

## 2. 整体风格标签

在待合成文本的**最开头**添加 `(风格)`。多个风格放在同一对括号内，分隔符不限，也支持自定义风格。

支持半角 `()`、全角 `（）` 和方括号 `[]`。

```text
(风格1 风格2)待合成内容
(慵懒)再让我睡五分钟……就五分钟，真的，最后一次。
```

| 风格类型 | 推荐风格 |
| --- | --- |
| 基础情绪 | 开心 / 悲伤 / 愤怒 / 恐惧 / 惊讶 / 兴奋 / 委屈 / 平静 / 冷漠 |
| 复合情绪 | 怅然 / 欣慰 / 无奈 / 愧疚 / 释然 / 嫉妒 / 厌倦 / 忐忑 / 动情 |
| 整体语调 | 温柔 / 高冷 / 活泼 / 严肃 / 慵懒 / 俏皮 / 深沉 / 干练 / 凌厉 |
| 音色定位 | 磁性 / 醇厚 / 清亮 / 空灵 / 稚嫩 / 苍老 / 甜美 / 沙哑 / 醇雅 |
| 人设腔调 | 夹子音 / 御姐音 / 正太音 / 大叔音 / 台湾腔 |
| 方言 | 东北话 / 四川话 / 河南话 / 粤语 |
| 角色扮演 | 孙悟空 / 林黛玉 |
| 唱歌 | 唱歌 |

**唱歌**：必须在文本最开头添加 `(唱歌)`，即 `(唱歌)歌词`。`唱歌`、`sing`、`singing` 等效，歌词建议使用中文。

## 3. 局部音频标签

在正文任意位置插入 `[音频标签]`，控制局部语气、情绪、呼吸、停顿、咳嗽与语速。

```text
(温柔 疲惫)怎么还没睡？……[轻笑]我没事，就是今天有点累。
```

| 控制类型 | 标签示例 |
| --- | --- |
| 语速与节奏 | 吸气 / 深呼吸 / 叹气 / 长叹一口气 / 喘息 / 屏息 |
| 情绪状态 | 紧张 / 害怕 / 激动 / 疲惫 / 委屈 / 撒娇 / 心虚 / 震惊 / 不耐烦 |
| 语音特征 | 颤抖 / 声音颤抖 / 变调 / 破音 / 鼻音 / 气声 / 沙哑 |
| 哭笑表达 | 笑 / 轻笑 / 大笑 / 冷笑 / 抽泣 / 呜咽 / 哽咽 / 嚎啕大哭 |

## 4. 官方 API 中的放置位置

两种控制方式在 `messages` 中的位置不同：

- **自然语言指导**：放在 `role: user` 的 `content` 中。
- **带标签的待合成文本**：放在 `role: assistant` 的 `content` 中。

## 在 VCP 通话中使用

以下是 VCP 的通话格式约定。风格指导规则会交给聊天模型，指导它生成本轮声音描述和回复；无需在设置中手写 API 请求。

1. 回复开头用 `<voice_guidance>` 包裹本轮的自然语言声音指导。
2. 闭合后换行，以 `(风格)` 开始正文。
3. 在正文中按需点缀少量 `[音频标签]`，只描述声音。

```text
<voice_guidance>
声音放松，语速稍慢，带一点刚睡醒的懒意。
</voice_guidance>
(温柔 慵懒)早呀。[轻笑]再陪我待一会儿吧。
```
