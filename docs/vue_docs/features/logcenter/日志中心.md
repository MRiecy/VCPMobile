# 日志中心（Log Center）

> 入口：右边栏「更多」工具盘 → 日志中心。
> 远程查看 VCPToolBox 服务器日志（`DebugLog/ServerLog.txt`）。
> 方案档案：`plan/vcpmobile-more-tools-research/01-日志中心-上游契约与移植方案.md`。

## 架构

```
LogCenterView.vue ── useVirtualList（固定行高 22px）
  └─ logCenterStore.ts ── invoke('logcenter_fetch' / 'logcenter_clear_server')
       └─ Rust vcp_modules/logcenter ── GET/POST /admin_api/server-log（Basic Auth）
```

- **Rust 侧**（`src-tauri/src/vcp_modules/logcenter/`）：纯认证代理 + 边界防护
  （8MiB 响应上限、首尾 U+FFFD 剥除、错误语义化）。无会话状态。
- **前端 Store**：增量协议状态宿主——`offset` / `pendingFragment`（半行拼接）/
  行缓冲裁剪（默认 500，可选 100–3000）/ 指数退避（3s→30s 封顶）。

## 关键机制

| 机制 | 说明 |
| --- | --- |
| 半行拼接 | 后端按字节切片，`splitLogChunk(content, carry)` 把末尾半行留待下次增量原位补全（移植自 AdminPanel-Vue useServerLogViewer，修复桌面版断行缺陷） |
| 轮转检测 | 响应 `needFullReload=true` 时丢弃缓冲、offset 归零全量重拉 |
| 生命周期轮询 | 页面关闭即停；`appLifecycleStore.isBackground` 退后台停、回前台立即补拉 |
| 级别着色 | `/\[(LOG\|INFO\|WARN\|WARNING\|ERROR\|FATAL\|DEBUG)\]/i` → 2px accent bar + 状态色文本 |
| 渲染安全 | 无 `v-html`；关键词高亮用 `splitByKeyword` 拆段渲染 `<mark>`；ANSI 控制码剥除 |
| 清空双轨 | 「清空本地显示」（轻）与「清空服务器日志」（危险，`showConfirm` 二次确认）分离 |

## 偏好持久化（localStorage）

`vcp_log_limit`（行数）、`vcp_log_reverse`（倒序）、`vcp_log_autoscroll`（自动滚动）。
