# 任务调度中心（Task Center）

> 入口：右边栏「更多」工具盘 → 任务调度。
> 远程调度 VCPToolBox 服务器上 VCPTaskAssistant 插件的 Agent 自动任务。
> 方案档案：`plan/vcpmobile-more-tools-research/02-任务调度中心-上游契约与移植方案.md`。

## 当前范围

- **S2a**：任务列表、启用拨钮、立即触发、执行历史、全局调度开关；
- **S2b**：任务编辑器（新建/编辑/删除，全屏分节表单）+ 异步委托追踪（只读 + 取消）。
- Agent 管理（AgentAssistant 配置编辑）不在移动端范围内（桌面端/AdminPanel 承担）。

## 架构

```
TaskCenterView.vue
  └─ taskCenterStore.ts ── invoke('task_*')
       └─ Rust vcp_modules/taskcenter ── /admin_api/task-assistant/*（Basic Auth）
```

- **Rust 侧**（`src-tauri/src/vcp_modules/taskcenter/`）：认证代理 + 200s 触发长超时 +
  taskId 百分号编码 + **全局开关 read-modify-write**（后端 POST /config 是全量覆盖语义，
  直接 PATCH 风格调用会清空任务列表——这是上游陷阱，切勿绕过）。
- **前端 Store**：首次 `task_get_config` 全量 → 之后 `task_get_status` 轻量轮询
  （有任务 running 时 2.5s，否则 5s；退后台停、回前台立即补拉）。

## 关键机制

| 机制 | 说明 |
| --- | --- |
| 乐观更新 | 启停/全局开关先改本地态，失败回滚 + Toast |
| 触发去重 | `triggeringIds` 集合做 in-flight 去重；后端派发同步等待 Agent（最长 3 分钟） |
| 插件缺失态 | Rust 把 503 语义化为 `PLUGIN_UNAVAILABLE:` 前缀 → 整页空态引导 |
| randomN 控件化 | 编辑器中「随机抽取开关 + 人数步进器」⇄ `randomN` 标签双向序列化（`draftFromTask`/`draftToPayload`），列表侧显示「随机抽 N 人」文案 |
| 状态表达 | 卡片 2px accent bar：绿=启用 / 蓝=运行中 / 红=上次失败 / 灰禁用降透明度 |
| 编辑器 | 全屏分节表单（滑入子页，非模态框）；`validateDraft` 前端镜像后端 `sanitizeTaskInput`；占位符 chips 光标处插入；interval 步进器对齐后端 10 分钟下限 |
| 委托追踪 | Tab 激活才 8s 轮询 `/agent-assistant/delegations`；取消走危险确认；运行中/最近记录分组展示 |
