# 邮箱（clawEmail / VCPClawMail）

> 入口：右边栏「更多」工具盘 → 邮箱。
> 查看/管理 Agent 的 ClawEmail 云端邮箱（MVP：账户切换 + 列表 + 详情 + 垃圾箱）。
> 方案档案：`plan/vcpmobile-more-tools-research/10-clawEmail-上游契约与移植方案.md`。

## 架构

```
MailListView.vue ── MailDetailView.vue（滑入子页）
  └─ mailStore.ts ── invoke('mail_state' / 'mail_list' / 'mail_read' / 'mail_trash')
       └─ Rust vcp_modules/mail ── /admin_api/claw-mail/*（Basic Auth）
                                     → VCPClawMail 插件 → ClawEmail 云（SDK）
```

- **无本地存储**：邮件本体在云端，列表/详情实时穿透；服务端 WS（WuKongIM）刷新
  热缓存，移动端 45s 轻量轮询 `state.updatedAt` 脏检查。
- **错误专态**：503 → 「插件未加载」；401 → 凭据提示；429 → 限流提示。

## 关键机制

| 机制 | 说明 |
| --- | --- |
| 寻址 | `addressingOf`：子邮箱传 `mailbox=mailN`（优先），公共邮箱传 `user=完整地址` |
| 分页 | `limit=20 + start offset` 增量加载；`unreadOnly` 开关 |
| 宽容解析 | `mailPartyText`（from/to string\|array\|object）、`parseMailDate`（未归一）、`readState` 三态（read/unread/unknown——SDK 可能不返回标志位） |
| 阅读无副作用 | 详情默认 `markRead=false`；「标为已读」为显式操作 |
| 垃圾箱 | 软删除（后端按名称识别垃圾箱文件夹），二次确认 |
| 轮询 | 前台 45s `state?refresh=false`；退后台停、回前台补拉（isBackground watch）；手动刷新走 `refresh=true` 穿透 |

## 能力边界

- **MVP**（现有上游端点）：账户切换 / 列表分页 / 详情 / 垃圾箱。
- **V1.1**（依赖上游补丁 VCPToolBox@`7c89ade9`，移动端已对接）：写信 / 回复 /
  文件夹切换 / 标读标未读 / 搜索 / 附件下载（`saveToDownloads` 系统下载目录）。
  补丁端点 404 时 `extendedApiSupported=false`，相关 UI 自动降级隐藏。
- 详情为 markdown 有损渲染；原始 HTML 已在补丁中出口（`html` 字段），保真渲染未做 UI。
